# SPEC-SECTOR-GRID-001 — 릴리스 노트 (사용자용)

> **목적**: 본 SPEC(M1~M6)이 만든 변화 중 "고장처럼 보이지만 **실은 올바른**" 변화를
> 미리 명시해, 리뷰어가 이를 회귀로 오인해 되돌리지 않도록 한다.
> 근거: `spec.md` §0.1 라이브 사용 가설 / acceptance.md §AC-SGR-020 (REQ-SGR-018).
>
> 아래 모든 변화는 AC-SGR-020 R1~R5 가 **기대값으로 고정**한 정상 결과다.
> 회귀 게이트: `tests/test_regression_sgr020.py`.

---

## TL;DR — 왜 화면이 바뀌어 보이는가

본 SPEC은 섹터 분석의 **기반 계층**(①)을 고쳤다. 사용자에게 보이는 화면 변화는
② 집계 / ③ UI가 이 올바른 기반 위에서 **재계산**한 결과다. 즉 "숫자가 바뀌었다" =
"이제 올바른 숫자다". 이전 숫자가 맞았던 것이 아니라, 다중 날짜 주·부분 데이터·중복
종목이 섞여 **틀린 채로** 표시되고 있었다.

---

## 기대되는 변화 (고장이 아닙니다)

### 1. rank(순위) 평균 약 3.5계단 이동
- **현상**: 섹터 랭킹의 순위가 기존과 다르게 나온다.
- **원인**: 기준일이 순진한 `MAX(Date)`(부분 데이터 날짜 가능)에서 **정규 격자 대표
  바**로 고정되었다(AC-SGR-006). 비교하는 두 날짜가 모두 올바른 완결 주 바다.
- **되돌림 금지**: 기존 순위는 부분 데이터 날짜를 기준으로 한 **틀린 값**이다.

### 2. 1주 초과수익률 양수 섹터 29/29 → 18/29
- **현상**: 단기 상승 섹터 수가 줄어든다.
- **원인**: rank_change 기준일이 `LIMIT 1 OFFSET 3`(11일 전, 원시 날짜 기준)에서
  `anchor(t, 28)`(**4주 전 정규 바**)로 이동했다(AC-SGR-020 R2). 비교 구간이 일관되게
  4주로 고정되어, 우연히 짧은 구간에서 양수로 잡히던 섹터가 사라진다.
- **되돌림 금지**: 이전 29/29는 비교 구간이 종목마다 달라 **재현성이 없던 값**이다.

### 3. 52주 신고가 종목 수 99 → 56
- **현상**: 신고가 종목 수가 크게 줄어든다.
- **원인**: 52주 기준이 원시 행 52개(=약 139일, 다중 날짜 주 중복·부분 데이터 포함)에서
  **정규 격자 52±1바(=약 364일)**로 고정되었다(AC-SGR-007 TG-1). 진짜 1년 기준으로
  재계산한 결과다.
- **되돌림 금지**: 이전 99는 약 4.5개월치만 본 **과대 계수**였다.

### 4. RS(상대강도) 평균 상승
- **현상**: RS 값이 전반적으로 올라간다.
- **원인**: RS 계산 기준일·히스토리가 정규 격자로 정렬되어 기준 KOSPI 대비가 일관되었다.
- **되돌림 금지**: 비교 기준이 일관된 올바른 값이다.

### 5. 복합점수(composite score) 절대값 변경
- **현상**: 복합점수의 스케일이 달라진다.
- **원인**: 입력 지표(rank, RS, 모멘텀 등)의 기준일·구간이 정규화되어 점수를 구성하는
  성분이 모두 올바른 기반에서 재산출된다.
- **되돌림 금지**: 구성 성분이 올바르므로 점수도 올바르다. 절대값 비교가 아닌
  **순위/분위**로 해석해야 한다.

### 6. KOSPI 필터 적용 시 디스플레이·스마트폰 섹터 제외
- **현상**: KOSPI만 보기 설정 시 일부 섹터가 빠진다.
- **원인**: 유니버스 단일 소스(UN-1/UN-2) 정합으로 종목의 market 출처가 registry로
  단일화되어 KOSPI/KOSDAQ 구분이 정확해졌다(AC-SGR-014).
- **되돌림 금지**: 이전에는 market 분류가 섞여 KOSDAQ 종목이 KOSPI에 섞여 있었다.

### 7. RRG 사분면 편중 변화 + 궤적 단축
- **현상**: RRG(Relative Rotation Graph)의 점 분포·궤적이 달라진다.
- **원인**: x축 날짜가 정규 격자(ISO 주당 1바)로 정렬되어 궤적 포인트 수가 약간
  줄고(AC-SGR-020 R4/R5), 각 포인트가 올바른 완결 주를 기준으로 한다. 궤적이 더
  짧고 일관되게 표시된다.
- **되돌림 금지**: 이전 궤적은 다중 날짜 주가 중복 바를 만들어 **왜곡**된 것이었다.

## 변하지 않는 것 (의도된 무변화)

- **미분류 섹터 센티널**(REQ-SGR-017): 현재 registry에 NULL/빈/`nan`/`기타` 행이
  0건이므로 화면 변화 없음(AC-SGR-021).
- **stale 종목 배제**(UN-5): 현재 `stale ∩ stock_meta = 0`이므로 화면 변화 없음
  (AC-SGR-017). 규칙은 구현되어 있으나 라이브에서 제외 대상이 없다.
- **게임 섹터 종목 수 32**: 중복(아이톡시 052770) 제거로 33 → 32. **1개 감소가 맞다.**
  (AC-SGR-020 R3).

## 재평가 시점 (spec §0.1)

본 SPEC의 가치 판정은 **② 집계 SPEC ship 이후 주중 갱신 1회 + 주말 갱신 1회를 실제로
돌린 뒤**(최소 1개 ISO 주 경과) "Bump 날짜 축이 균일해 보이는가"로 확인한다.
그 전에는 가치를 판정하지 않는다.

## 만약 차트가 너무 빈약해 보인다면

격자 정규화로 히스토리 포인트 수가 줄어 차트가 빈약해 보인다면, **①의 조회 필터는
유지한 채** `weeks` 기본값을 늘리는 조정으로 대응한다(spec §0.1 폐기 조건 — SPEC 폐기
대상 아님).
