# SPEC-AI-REPORT-001: Acceptance Criteria

## 시나리오 1: 정상 AI 분석 플로우

**Given** 사용자가 차트 그리드에서 "삼성전자(005930)" 종목을 보고 있고, `PERPLEXITY_API_KEY` 환경 변수가 설정되어 있을 때
**When** 사용자가 AI 버튼을 클릭하면
**Then** AI Report 모달이 열리고, "분석 결과" 탭이 활성 상태이며, Perplexity API 응답이 실시간으로 마크다운 렌더링되어 표시된다

## 시나리오 2: 리포트 자동 저장

**Given** AI 분석 스트리밍이 완료되었을 때
**When** SSE 스트림의 마지막 이벤트가 수신되면
**Then** `backend/reports/삼성전자/2026-04-12.md` 파일이 생성되고, 완전한 마크다운 콘텐츠가 저장된다

## 시나리오 3: 동일 날짜 재분석

**Given** `backend/reports/삼성전자/2026-04-12.md` 파일이 이미 존재할 때
**When** 같은 날 삼성전자에 대해 다시 AI 분석을 실행하면
**Then** `backend/reports/삼성전자/2026-04-12_2.md` 파일이 생성된다 (기존 파일 유지)

## 시나리오 4: 히스토리 조회

**Given** 삼성전자에 대한 분석 리포트가 3건 저장되어 있을 때 (2026-04-10.md, 2026-04-11.md, 2026-04-12.md)
**When** 사용자가 "히스토리" 탭을 클릭하면
**Then** 3건의 분석 날짜가 최신순으로 정렬되어 표시된다

## 시나리오 5: 저장된 분석 조회

**Given** 히스토리 탭에 분석 목록이 표시되어 있을 때
**When** 사용자가 "2026-04-10" 항목을 클릭하면
**Then** 해당 날짜의 저장된 마크다운이 모달에 렌더링된다

## 시나리오 6: 클립보드 복사

**Given** AI 분석이 완료되어 전체 마크다운이 표시된 상태일 때
**When** 사용자가 복사 버튼을 클릭하면
**Then** 원본 마크다운 텍스트가 클립보드에 복사되고, "복사됨" 시각적 피드백이 표시된다

## 시나리오 7: 모달 닫기 및 스트림 중단

**Given** AI 분석 스트리밍이 진행 중일 때
**When** 사용자가 ESC 키를 누르거나 backdrop을 클릭하면
**Then** 모달이 닫히고, SSE 연결이 즉시 중단(abort)되며, 불완전한 리포트는 저장되지 않는다

## 에지 케이스

### EC-001: API 키 미설정

**Given** `PERPLEXITY_API_KEY` 환경 변수가 설정되지 않았을 때
**When** AI 버튼을 클릭하면
**Then** 모달에 "AI 분석 서비스를 사용할 수 없습니다. 관리자에게 문의하세요." 에러 메시지가 표시된다

### EC-002: 네트워크 오류

**Given** AI 분석 스트리밍 중 네트워크 연결이 끊겼을 때
**When** SSE 연결이 실패하면
**Then** 수신된 부분 텍스트까지 표시하고, "연결이 끊겼습니다" 에러 메시지와 "다시 시도" 버튼이 나타난다

### EC-003: Perplexity API 에러 응답

**Given** Perplexity API가 429 (Rate Limit) 또는 500 에러를 반환했을 때
**When** 백엔드가 에러 응답을 수신하면
**Then** SSE를 통해 에러 이벤트가 전송되고, 프론트엔드에 사용자 친화적 에러 메시지가 표시된다

### EC-004: 존재하지 않는 종목 코드

**Given** 유효하지 않은 종목 코드 "999999"로 요청했을 때
**When** `/api/ai-report/999999` POST 요청이 들어오면
**Then** HTTP 404 응답과 "종목을 찾을 수 없습니다" 메시지가 반환된다

### EC-005: 동시 분석 요청 차단

**Given** 삼성전자(005930) AI 분석이 이미 진행 중일 때
**When** 같은 종목에 대해 추가 분석 요청이 들어오면
**Then** HTTP 429 응답과 "이미 분석이 진행 중입니다" 메시지가 반환되며, 프론트엔드에서 해당 메시지를 표시한다

### EC-006: 특수문자 포함 종목명

**Given** 종목명에 특수문자가 포함된 종목(예: "LG에너지솔루션")에 대해 분석을 요청했을 때
**When** 리포트 저장 시
**Then** 파일 시스템에서 안전한 경로가 생성되고 정상적으로 저장된다

### EC-007: 빈 히스토리

**Given** 특정 종목에 대한 이전 분석 리포트가 없을 때
**When** 히스토리 탭을 클릭하면
**Then** "아직 분석 이력이 없습니다" 빈 상태 메시지가 표시된다

### EC-008: 대용량 응답 처리

**Given** Perplexity API가 매우 긴 응답(10,000 토큰 이상)을 반환할 때
**When** 스트리밍으로 수신하면
**Then** 모달 내에서 스크롤 가능하게 렌더링되며, 성능 저하 없이 표시된다

## 시나리오 8: 출처 밀도 검증

**Given** 사용자가 삼성전자(005930)에 대해 AI 분석을 요청
**When** 분석이 완료되어 MD 파일로 저장되었을 때
**Then** 파일 내 `[N]` 형식 출처 마커가 15개 이상이며, 인용된 출처는 모두 도메인 whitelist에 포함된다

## 시나리오 9: 서술 문단 검증

**Given** AI 분석 리포트가 생성됨
**When** 리포트 구조를 검사
**Then** 각 `##` 섹션(0단계~6단계)마다 표 외에 최소 1개의 서술 문단이 존재한다

## 시나리오 10: 저품질 소스 제외

**Given** AI 분석 리포트가 생성됨
**When** 출처 URL을 확인
**Then** youtube.com, tistory.com, blog.naver.com, instagram.com 도메인의 URL이 0건이다

## Quality Gate

- [ ] 모든 EARS 요구사항(FR-001~FR-012) 구현 완료
- [ ] 모든 에러 처리 요구사항(ER-001~ER-006) 구현 완료
- [ ] 비기능 요구사항(NFR-001~NFR-004) 충족
- [ ] 7개 시나리오 전체 통과
- [ ] 8개 에지 케이스 전체 대응
- [ ] 기존 차트 셀 기능(%, RS, +, FS, TR) 회귀 없음
- [ ] SSE 스트리밍 3초 이내 첫 청크 수신
- [ ] 한글 종목명 파일 저장 정상 동작

## Definition of Done

1. AI 버튼이 ChartCell 툴바에 정상 렌더링
2. 클릭 시 Perplexity API 호출 및 SSE 스트리밍 동작
3. 모달에서 마크다운 실시간 렌더링
4. 분석 완료 시 파일 자동 저장
5. 히스토리 탭에서 이전 분석 조회 가능
6. 복사 버튼 정상 동작
7. 모든 에러 케이스 처리
8. 기존 기능 회귀 없음
