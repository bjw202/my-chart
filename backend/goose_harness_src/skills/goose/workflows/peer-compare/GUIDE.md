# 동종기업 비교

[조사 계약](../stock-report/references/research-contract.md)과 [역할 계약](../stock-report/references/agent-team.md)을 적용합니다. 비교 대상이 없으면 사업 유사성과 지역/제품을 기준으로 후보를 설명하고 필요한 대상을 선정합니다. 원자료 없이 기업 순위를 만들어내지 않습니다.

각 회사의 제품·부문 범위, 회계연도, 기간, 통화, 환율 기준, 연결 여부를 먼저 정렬합니다. 매출성장·마진·현금흐름·투자·부채·경쟁사 공급 진척을 비교합니다. 부문실적과 연결실적, DRAM전체와 HBM, 달력분기와 회계분기를 섞지 않습니다. 미확보 항목은 비교불가로 둡니다. 시장성장과 개별기업 상대성장, 점유율과 기술수준은 구분합니다.

결과는 비교 기준표, 주요 차이, 각사의 강점/약점, 핵심 반증과 판단변경 지표, 출처·수치 원장입니다. 관련 earnings-review 자료를 재사용하며 필요한 추가 조사만 수행합니다. standalone이면 fact-check 검토를 연결하고 비교 메모를 제시합니다. leaf이면 industry-notes와 원장 조각만 반환합니다. 전체 HTML 요청이면 검토 뒤 stock-report의 render 단계로 전달합니다.
