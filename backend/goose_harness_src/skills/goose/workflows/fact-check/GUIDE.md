# 독립 근거 검토

[조사 계약](../stock-report/references/research-contract.md)과 [역할 계약](../stock-report/references/agent-team.md)을 읽습니다. 검토 대상 원문·주장목록·출처·계산을 받고 작성자의 결론/PASS를 증거로 대신하지 않습니다. 핵심 주장과 중요한 반론을 직접 읽은 원자료에 대조합니다.

주장별로 근거충분/조건부/근거부족/반증을 표시하고 사실·전망·추론을 구별합니다. 여러 재전재와 동일회사 자료는 독립근거가 아닙니다. 단위·기간·분모·귀속·현금범위, 계획과완료, 본문과요약카드의 표현을 검사합니다. 특히 강한 반대근거가 결론에서 일반론으로 희석되거나 누락됐는지 봅니다.

실제발견마다 위치/영향/원문/정확한 수정권고를 남깁니다. 이번 직접열람, 과거열람 기록 대조, 재접근실패를 분리합니다. 중요결함 수정후 해당변경만 재검토하고 최초지적→해소/잔여상태를 기록합니다. 검토대상 밖 자료의 전수검증/감사/PDF/UI검증까지 통과했다고 표현하지 않습니다. standalone은 팩트체크표를 전달하고 leaf는 review.md와 근거지도를 반환합니다. 모델지정은 실제 지원될 때만 적용하고 사용모델을 사실대로 기록합니다.

## 최종 편집 검토

팩트 대조 후 보고서 기준의 편집 품질 게이트도 검토합니다. 의견이 조사 우선순위와 가격 적정성을 혼동하는지, 각 조사자의 중요한 반대 논거가 빠졌는지, 최소 다섯 문장만 채운 요약문으로 끝났는지 확인합니다. 사실 검토·내용 편집·브라우저 시각 검토의 결과와 한계를 분리해 남깁니다. 조사 자료를 더 읽지 않고 구조 검사만 통과시킨 것을 최종 품질 통과로 표시하지 않습니다.

## 생성 후 제출 감사

`phase=audit`는 렌더된 HTML과 현재 입력에 대한 제출 전 감사입니다. [최종 감사 계약](references/delivery-audit.md)을 읽고 실제 자료·계산·본문·화면을 감수한 뒤 [감사기](scripts/audit_report.py)를 실행합니다. revise이면 결함과 담당 역할을 구스 에이전트에 반환합니다. 분석 전 팩트체크를 했다는 이유로 생성 후 감수를 생략하지 않습니다.
