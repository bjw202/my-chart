# Goose 예약 실습

스킬은 방법을 제공하고 호스트의 실제 예약 기능이 시점을 관리합니다. 예약 예문·강의 자료 작성 요청만으로 사용자의 계정에 반복 작업을 만들지 않습니다. 사용자가 실제 예약을 요청한 경우 같은 이름·목적의 기존 일정을 찾아 중복을 피하고, 시장·시간대·주기·전달 위치를 확정한 뒤 해당 호스트 도구로 등록합니다. 등록 결과의 일정 ID·상태·다음 실행시각을 확인하기 전 예약 완료라고 하지 않습니다. HTML 생성 성공은 별도의 첫 실행 결과로 검증합니다.

## 강의 권장값 — 사용자가 조정 가능

- 국내: 월~금 16:10 Asia/Seoul. KRX의 당일 정규장 종료·특별 개장시간·휴장을 확인합니다. NXT·시간외 거래를 KRX 정규장과 합치지 않습니다.
- 미국: 월~금 16:30 America/New_York. 정규장 종료와 조기폐장·휴장을 확인합니다. 한국시간으로는 서머타임에 다음 날 05:30, 표준시에 06:30입니다. 시간대 지정이 안 되는 도구에는 한국시간 화~토 06:30 예시를 쓰되 지연 제공임을 명시하고 날짜를 다시 검증합니다.
- 휴장: 휴장 기록만 남기며 전일 보고서를 새 날짜로 재발행하지 않습니다.
- 자료 지연: 확인된 범위의 한계 명시 보고서로 전달하거나 재확인이 필요함을 알립니다. 자동 재시도는 호스트 지원과 사용자 설정 범위에서만 수행하며 무한 반복하지 않습니다.

## 호스트별 안내

ChatGPT: Scheduled/예약하기에서 작업을 만들고 설치한 Goose 접근·웹 조사·파일 생성이 실행 환경에서도 가능한지 한 번 실행합니다. 예약 설정은 저장되어도 스킬·파일 접근이 실패할 수 있습니다. 채팅 첨부나 프로젝트 파일 접근을 가정하지 않습니다.
Claude: 예약 가능한 Cowork/통합 환경에서 Scheduled 또는 자연어로 일정 초안을 만들고 Schedule을 눌러 등록합니다. 계정·조직 설정에 따라 기능이 달라집니다. 메뉴와 명칭은 실제 화면을 따릅니다.
지원하지 않는 환경: 실행 가능한 1회 요청과 예약용 프롬프트를 제공하고 미등록이라고 명시합니다. 알림만 등록된 것을 보고서 자동 생성 성공으로 표시하지 않습니다.

## 수강생 실습 순서

1. 최근 완료된 거래일 1회 생성 → 파일을 열어 근거·데이터 시각·한계를 점검합니다.
2. 같은 지침을 예약 기능에 넣고 시간대·요일·Goose 버전·결과 위치를 확인합니다.
3. 등록 ID·다음 실행시간을 확인한 뒤 첫 실행 또는 지금 실행 결과에서 HTML을 다운로드합니다.
4. 출처 장부·판단 변경 조건을 확인하고 다음 실행 전 중지/수정 방법까지 연습합니다.
