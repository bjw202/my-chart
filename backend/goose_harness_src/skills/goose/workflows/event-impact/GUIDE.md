# 사건의 영향 분석

[조사 계약](../stock-report/references/research-contract.md)과 [역할 계약](../stock-report/references/agent-team.md)을 적용합니다. 사건일·보도일·수정일을 구분하고 네이버 기사에서 원 언론으로 추적합니다. 익명 취재, 인터뷰, 회사 주장, 공시 확정 사실을 분리합니다.

원 보도→회사/당국 설명→정정/후속 집행을 확인합니다. 사건→가격/물량/원가/투자→이익/현금→판단의 경로를 조건부로 설명합니다. 기사상 주가반응을 주문감소나 사업악화의 증거로 바꾸지 않습니다. 긍정·부정 관점의 가장 강한 근거를 함께 확보합니다. 허가 법적효력·계약 세부·IPO조건이 공개되지 않았다면 확정값으로 계산하지 않습니다.

결과는 시간순 사건표, 실제 달라진 사실, 영향 경로와 성립 조건, 반론, 다음 확인사항, 출처 장부입니다. 심층 분석 leaf는 news-notes만 반환합니다. standalone은 fact-check로 핵심 사실을 대조한 뒤 사건 메모를 제시합니다. 자동 알림이나 외부 게시 요청으로 확대하지 않습니다.

오늘 기준 요청은 실제 현재 날짜·시간대를 확인하고 조사 마감 시각까지 최신 기사·공시·정정·후속 사건을 검색합니다. [최신성 기록](../fact-check/references/delivery-audit.md)에 검색식·시각·채널·결과와 직접 읽은 원문을 연결합니다. 네이버 발견과 원 언론 본문 열람을 구분하며 오래된 자료의 날짜만 바꾸지 않습니다.
