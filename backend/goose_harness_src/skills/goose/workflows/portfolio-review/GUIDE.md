# 보유자산 상담과 조정 시나리오

[조사 계약](../stock-report/references/research-contract.md), [역할 계약](../stock-report/references/agent-team.md), [실행 지도](../stock-report/references/workflow-map.json)를 적용합니다. 평단가·수량·통화·보유현금·계좌 범위를 확인합니다. 계좌번호·비밀번호·주문권한은 필요하지 않습니다. 외부 시세검색에는 종목만 전달하고 사용자의 잔고·원가·자산명세를 넣지 않습니다.

계산 전에 [입력 형식](references/portfolio-input.md)을 읽고 scripts/portfolio_calc.py를 실행합니다. 시세·환율의 기준일/출처를 직접 확인합니다. 평단가가 수수료/세금/기업행동을 반영했는지 확인하고 계산 원가의 범위를 표시합니다. 미실현손익과 배당·실현손익을 포함한 총수익률을 구별합니다. 부분 계좌나 누락 시세를 전체 자산으로 일반화하지 않습니다.

상담은 투자목적·기간·현금 필요·감내 가능한 손실·다른 주요 자산/부채 범위·세금/계좌 및 거래 제약을 필요한 수준으로 확인합니다. 계산은 가능한 입력으로 먼저 수행하되 목표가 없으면 임의 목표비중을 확정 권고하지 않습니다. 목적에 맞는 조건부 대안을 설명하고 선택한 목표를 명시합니다. 손실회복·평단가 낮추기 자체를 투자논리로 삼지 않습니다.

필요한 기업 분석·새 사건·실적·비교 조사는 총괄이 실행 지도에 따라 연결하고 결과를 이 스킬에 전달합니다. 모든 종목에 긴 보고서를 무조건 생성하지 않고 계좌의 중요한 위험과 사용자 범위에 맞춥니다. 기업의 관심목록 의견과 계좌의 적정 비중은 분리합니다. 관심종목 편입이라고 보유비중을 반드시 늘리는 것은 아닙니다.

현재유지 / 새자금으로 조정 / 기존비중 조정의 가정·거래비용·세금 미반영·현금 여력·집중위험을 비교합니다. 목표비중 계산은 명시된 목표/제약으로만 하며 예시 수익률을 실현 전망으로 보장하지 않습니다. 리밸런싱 산술과 사용자에게 적합한 전략 판단은 별도입니다. 총괄이 최종 fact-check를 한 번 수행한 뒤 손익·집중도표와 상담 보고서를 제시합니다. 실제 거래는 실행하지 않습니다. 장기세금/법률 결론에는 해당 관할 최신공식자료를 확인하고 필요한 전문상담 사항을 짧게 구분합니다.

leaf에서는 다른 스킬을 호출하지 않고 지정 phase만 수행합니다. prepare는 입력/목표 확인과 가능한 산술 계산·자료 공백/조사 요청 목록만 반환합니다. compose는 총괄이 전달한 시세·기업 분석·뉴스·목표를 종합해 조건부 대안을 작성합니다. standalone은 실행 지도의 해당 흐름만 임시 총괄로 한 번 실행합니다.
